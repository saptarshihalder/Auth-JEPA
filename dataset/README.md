# Datasets

Each folder: `files.csv` (exact files used) and a few example 512 x 512 crops. Full datasets are not redistributed.

| Folder | Dataset | Images | Source |
|---|---|---|---|
| `training/RAISE` | RAISE, 3 Nikon cameras | 848 | http://loki.disi.unitn.it/RAISE/ |
| `training/VISION` | VISION, 10 phones | 903 | https://lesc.dinfo.unifi.it/VISION/ |
| `test/real_RAISE` | RAISE, real test photos | 1,140 | http://loki.disi.unitn.it/RAISE/ |
| `test/Synthbuster` | 8 generators | 1,200 | https://zenodo.org/records/10066460 |
| `test/SD3_FLUX` | SD3 and FLUX | 2,000 | Synthbuster extension |
| `test/OpenFake` | 15 generators | 3,485 | https://huggingface.co/datasets/ComplexDataLab/OpenFake |

`counts.csv` lists the number of images per folder.
